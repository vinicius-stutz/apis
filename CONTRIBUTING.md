# Contribuindo
Contribuições são bem-vindas! Para adicionar ou atualizar uma API:

1. Faça um **fork** deste repositório
2. Edite o arquivo correspondente em `collection/` (use o padrão de tabela existente)
3. Atualize o `README.md` se necessário
4. Abra um **Pull Request** com uma descrição clara da mudança

> [!TIP]
> 
> Ao adicionar uma API, verifique se ela ainda está ativa, se é gratuita (ao menos em plano básico) e preencha corretamente as colunas **Auth**, **HTTPS** e **CORS**.
